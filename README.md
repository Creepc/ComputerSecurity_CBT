# 컴퓨터보안 MIDTERM LAB

PPT 1~4장(실제 표시 순서 기준 총 248슬라이드)을 분석해 만든 한국어 149개 개념 노트와 462문항 문제은행입니다. PPT의 실제 페이지 순서와 관계 파일을 기준으로 근거 번호와 발표자노트를 연결합니다. 제공된 중간고사 예시의 학습문항 비율(서술 9·단답 1·객관 3)을 실전 연습에 반영했습니다.

- 1~4장 단위 개념 학습: 장 전체 이어 읽기·일괄 읽기 완료·장 전체 문제 스크롤 풀이
- 문제 검색·장·유형·난이도·상태 필터
- 장별 모든 문제를 한 페이지에서 풀고 각 문항 바로 아래에서 정답·선택지별 해설 확인
- 문항별 답안·채점·서술 루브릭 자동 저장과 백업·복원
- 서술형 키워드 힌트, 키워드 뜻·답안 구성 순서, 키워드로 다시 쓰기
- 문제 해설 안에서 관련 개념의 정의·원리·예시·핵심 구분까지 함께 학습
- 직접 답안 작성, 모범답안과 채점 요소로 서술형 자기평가
- 시간 제한 모의고사, 답안 저장과 새로고침 후 이어 풀기
- 오답·북마크·개인 메모, 암기 카드와 취약 개념 분석
- 브라우저 로컬 기록, JSON 백업·복원, 반응형 화면과 다크 모드

## 실행

Node.js 22와 Python 3를 사용합니다. 추가 패키지 설치 없이 실행됩니다.

```sh
npm test
npm run build
npm run dev
```

브라우저에서 `http://127.0.0.1:4175`를 엽니다. `file://`로 직접 열면 JSON을 가져올 수 없습니다.

## 배포

GitHub Pages를 Actions 방식으로 설정하면 `main`에 푸시할 때 검증 후 `dist/`를 배포합니다. 상대경로와 해시 라우팅을 사용하므로 저장소 하위 경로와 직접 공유한 문항 링크도 동작합니다.

원본 PPT·HWP, 시험 이미지, 추출 원문과 분석 중간자료는 `analysis/`에 보관하고 Git에서 제외합니다. 공개 결과는 자체 작성한 개념 설명과 연습문제입니다. 학습기록은 서버로 전송하지 않습니다.

## 내용 검증

`scripts/validate.mjs`는 문항 ID·발문 중복, 정답 범위, 선택지별 해설, 개념 참조, 근거 슬라이드와 미출제 개념을 확인합니다. 슬라이드별 내용 연결 보고서는 비공개 `analysis/validation-report.json`에 생성됩니다. `tests/`에서는 시험 구성, 득점과 저장·복원 로직을 검사합니다.

단답 자동 채점은 등록된 동의어를 정규화해 비교하며, 서술형은 채점 요소에 따른 자기평가입니다. 시험 시간·배점은 연습용입니다. 과거 시험지와 현재 PPT 범위의 차이 및 자료의 혼동 포인트는 웹의 ‘시험 양식 · 자료 분석’에 설명했습니다.

## 2026-10-19 벼락치기 핵심

`#/cram`에 기출과 현재 범위가 겹치는 11주제와 현재 자료의 과정·비교 성향 적용 1주제를 모았습니다. XSS·CSRF는 직접 기출과 구분해 표시합니다. 별도 예상 24문항, 암기 문장·핵심 용어·모범답안·채점 체크 요소·전보기 해설을 제공하며 기존 462문항의 점수와 분리합니다. 답안 전체 가리기·펼치기, 직접 작성, 설명 가능한 주제 체크와 미암기 필터를 지원합니다. 작성 답안과 암기 상태도 기존 JSON 백업·복원에 포함됩니다.

각 벼락치기 주제에는 암기 구호·개념에 연결하는 연상법·혼동 구별 팁·가리고 떠올릴 질문을 함께 제공합니다. 앞쪽 핵심 암기표에도 구호를 표시하며 회상 모드에서는 암기 팁도 숨깁니다.
